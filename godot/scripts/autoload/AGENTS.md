# AGENTS.md: godot/scripts/autoload/

These are the three hand-written singletons, registered in `godot/project.godot` `[autoload]`. The load order is
Story, Game, Audio, and everything else reaches them by these names.

| Autoload name | Script | Role |
|---|---|---|
| `Story` | `story.gd` | loads `res://data/story.json` (`PATH`) and `res://data/world.json` (`WORLD_PATH`, exposed as `Story.world`); lookups (`quest`, `chapter`, `volume`, `npc`, `map_name`, `item_name`, `speaker_name`); cultivation naming (`realm_name`, `stage_name`, `realm_label`); `fill()` token substitution ({player} {junior} {senior} {sibling} {they} {them} {their}); `visible_lines()` (conditional lines); `voice_path()` (picks `_m` / `_f` takes); `reading_time()`; `threads_so_far()` / `latest_beat()` for the "Story So Far" page |
| `Game` | `game_state.gd` | persistent progress: quest / objective index, `realm` (0-11) and `stage` (0-10), alignment `law` / `good` (-100..100), `flags`, `attitude`, `choices`, inventory, active character, visited maps; `cond_ok()`, `apply_choice()`, `alignment()`; saves `user://save.json` (`SAVE_VERSION` 3) after every objective; test hooks `fast`, `choice_seed`, `auto_choice()` |
| `Audio` | `audio.gd` | `play_music(id, fade)` with cross-fades (`res://audio/music/`), `sfx(id, db, pitch)` pooled players (`res://audio/sfx/`, `LOOPING` ids loop), `play_voice(path)` / `stop_voice()` / `voice_playing()`; `music_volume` / `voice_volume` setters apply immediately |

## Conventions and pitfalls

- `Story` never writes data. story.json and world.json are generated by `tools/build_story.py` and
  `tools/world_spec.py`. New fields must be added in those tools, and then read here with a
  `.get(key, default)`, so older data keeps loading.
- Save compatibility: bump `SAVE_VERSION` when the save format changes, and keep loading older saves. v3 recomputes
  cultivation from the story for older saves, as docs/STORY.md describes.
- Condition keys that `Game.cond_ok()` understands (`align`, `align_law`, `align_good`, `min_realm` / `max_realm`,
  `min_stage` / `max_stage`, `flag` / `not_flag`, `likes` / `dislikes`) must match what `tools/build_story.py`
  validates. Change both together.
- Audio: a running cross-fade is killed before the next one starts (runtime.md #40). Looping is set on the stream in
  `_stream(path, loop)`, never in the `.import` files. Anything that starts a looping SFX must stop it in its own
  `_exit_tree()` (runtime.md #72).
- Autoloads survive scene changes. Guard any reference to game nodes (map, player) with `is_instance_valid`.

Test: `~/godot/godot --headless --path godot -s res://tests/smoke_test.gd` (story lines, voices, portraits, conditions,
a `save_dict()` / `load_dict()` round trip),
plus a walkthrough shard for anything that touches progress or conditions.
